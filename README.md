# 🎬 StreamFlix Clone

A modern and responsive **movie streaming website UI** built using **HTML5 and CSS3**.
StreamFlix provides a clean, attractive, and user-friendly interface inspired by popular streaming platforms.

🔗 **Live Demo:**
https://priyanshubarnawal28.github.io/streamflix-clone/

---

## 📌 About The Project

**StreamFlix Clone** is a frontend web development project created to practice and demonstrate modern **HTML and CSS** skills.

The website contains a streaming-platform-style interface with movie sections, navigation menus, movie cards, images, and a responsive layout.

This project focuses on creating a visually appealing movie streaming website without using any frontend framework.

---

## ✨ Features

* 🎬 Modern movie streaming UI
* 📱 Responsive design
* 🧭 Navigation bar
* 🎞️ Movie cards and poster sections
* 🖼️ Movie poster images
* 📺 Streaming-platform inspired layout
* 🎨 Custom CSS styling
* ⚡ Lightweight and fast
* 💻 Works on desktop and mobile screens
* 🌐 Hosted using GitHub Pages

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/priyanshubarnawal28/streamflix-clone.git
```

### 2. Open the Project

```bash
cd streamflix-clone
```

### 3. Run the Website

Open the `index.html` file directly in your browser.

You can also use **VS Code Live Server** to run the project locally.
